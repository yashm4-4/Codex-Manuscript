# Public alternative COPD GWAS: provider access and schema audit

Scope: preflight only. The audit retained 43 public responses totaling 8,166,644 bytes, with URL, UTC, HTTP status, requested byte range, response headers, size and SHA-256. All retained-byte hashes pass. There was no whole-GWAS download, locus enumeration, fine-mapping, inference, candidate lookup or benchmark access. The structured record is [alternatives_audit.json](alternatives_audit.json); [`downloads/`](downloads/) holds original responses and receipts. Partial-response hashes **are not whole-source checksums**.

## Source-specific evidence and caveats

BBJ's [original README](https://humandbs.dbcls.jp/files/hum0014/hum0014_v17_v18_v21_README.txt) resolves allele orientation and describes SAIGE0.29.4.2, MAC>=10 and the autosomal/sex-stratified file conventions. The [sample sheet](https://humandbs.dbcls.jp/files/hum0014/hum0014_v17_v18_v21_sample_size.xlsx) confirms male 2,855/103,089 and female 460/98,503. [Archive evidence](bbj_archive_schema_evidence.json) records the central directory and all four actual headers: all-sex autosomal/chrX and sex-stratified autosomal/chrX. Male `BETA.x/SE.x/p.value.x` and female `BETA.y/SE.y/p.value.y` share each sex-stratified member; no per-variant N column is present there, so the sample-sheet counts require later missingness validation. Do not mistake `metabeta/metase` for either sex-specific result. JENGER timeouts and the absent Catalog mirror do not negate successful NBDC access. Public fine-mapping results elsewhere do not establish original LD access. Physician diagnosis is supported by the retained primary Ishigaki paper, not inferred from ICD indexing alone.

Pan-UKB's [file documentation](https://pan.ukbb.broadinstitute.org/docs/per-phenotype-files/index.html), [QC documentation](https://pan.ukbb.broadinstitute.org/docs/qc/index.html) and full retained manifest establish its coding and counts. Ancestry-specific columns must be selected explicitly: one file also contains meta-analysis columns. A provider complete-release designation plus nonsignificant preview rows supports a genome-wide resource, not an assertion that every locus has already passed density or LD coverage checks.

GBMI's [official resource page](https://www.globalbiobankmeta.org/copy-of-participating-groups) links the retained workbook. Its exact schema and COPD cohort memberships are in [gbmi_workbook_extracted_metadata.json](gbmi_workbook_extracted_metadata.json). The first fetch helper conservatively marked this chunked response as potentially partial; independent ZIP central-directory and member-CRC checks establish a complete workbook. The original receipt is preserved, with the interpretation explicitly corrected in the consolidated audit. GBMI's published weighted r-squared diagnostics are not a signed LD matrix for summary-statistic fine-mapping.

FinnGen [R11 schema](https://finngen.gitbook.io/documentation/r11/data-description.md), [endpoint methods](https://finngen.gitbook.io/documentation/r11/methods/endpoints.md) and [manifest](https://storage.googleapis.com/finngen-public-data-r11/summary_stats/finngen_R11_manifest.tsv) are release-specific evidence. The official instructions request registration for download guidance, although the tested public GCS endpoint responded anonymously; this audit did not submit a form. A public SISu-reference LD query service does not by itself establish a dense R11 association-sample matrix.

The [MVP release instructions](https://www.ncbi.nlm.nih.gov/projects/gap/cgi-bin/GetPdf.cgi?id=phd008760.1) distinguish GIA from HARE and suppress ancestry-specific releases below 500 cases. EAS PheCode496 has 423 cases in accession metadata; no released dense payload was verified. Catalog mirrors and the [provider application route](https://www.mvp.va.gov/pwa/discover-mvp-data) are separate access paths. Harmonized effect-allele fields, not an unchanged auxiliary `alt` field, determine orientation after harmonization.

[GEMINI's deposition](https://doi.org/10.5281/zenodo.14284047) has a COPD-specific README identifying UKB+FinnGen despite the repository-wide description mentioning consortium data. [Extracted source metadata](gemini_COPD_source_metadata.json) preserves that distinction. CKB's [access policy](https://pheweb.ckbiobank.org/about) requires an application for keys and prohibits sharing keys or decrypted statistics outside the immediate group; its CC BY4.0 statement does not remove these additional conditions.

## Recommendation and stopping boundary

For a direct-COPD primary, BBJ is source-accessible and scientifically eligible by phenotype, but not yet executable with verified dense matched LD. Consider it alongside the root audit's European direct-COPD anchors, not as a replacement for their investigation. Pan-UKB J44 EUR is the strongest technically promising **secondary** option because ancestry-specific signed statistics and same-project dosage LD exist. Its LD scaling and sample compatibility still need the prospective gates in the companion LD/methods audit. No dataset here is declared fine-mapping-ready now.

All UKB-derived studies may overlap; BBJ, FinnGen and CKB appear in broader meta-analyses; male/female subsets are not independent replications. Do not silently pool phenotypes, ancestries, releases or cohorts. Machine-learning COPD and chronic-bronchitis strata remain separate. No usable-locus count was estimated from candidates or preview rows. Actual eligible loci remain unknown until authorized whole-GWAS QC and independent GWAS-derived locus definition; no COPD-specific published count was verified in this provider sub-audit.
