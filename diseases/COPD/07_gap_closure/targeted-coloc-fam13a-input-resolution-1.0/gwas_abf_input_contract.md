# Track-A GWAS approximate-Bayes-factor input contract

**Decision: NOT CLEARED.** The frozen GCST90016588 native file is a GRCh37 ever-smoker marginal spirometric COPD case-control GWAS. The frozen interval is `A_chr4_88300892_91560531`, inclusive, defined before this stage by GWAS significance and ±1.5 Mb merging. It has 12,094 source rows, 51 at P < 5×10⁻⁸. The source headers are `effect_allele`, `other_allele`, `odds_ratio`, `standard_error`, `p_value`; the frozen audit and [PLINK 2 format contract](https://www.cog-genomics.org/plink/2.0/formats#glm_logistic) support beta = ln(reported OR), and supplied SE on the log-odds scale. This is a documented convention and strong consistency evidence, but the exact historical command/submission conversion was unavailable; it is not proof of an unmodified regression SE in every row. SE is never reconstructed from P here.

The paper reports 12,446 cases and 59,145 controls (nominal N = 71,591, case fraction = 0.1738486681), MAF ≥ 0.01 and imputation r² ≥ 0.5. No per-variant N, allele frequency, imputation quality, or case/control counts appear in the GWAS summary file. Nominal N therefore cannot be certified as each variant's analyzed N. The FAM13A region has **32** frozen rounding-aware OR/SE/P failures; **15** have an exact QTL variant before rejection. All 32 remain excluded from any proposed ABF input. The top native GWAS row (GRCh37 position 89,834,173; P = 2.25222×10⁻¹⁰) lacks a unique usable provider harmonized row, independently material to regional inference. The 51 significant rows reduce to 39 eligible exact overlaps under the strict identity/statistic gate.

The beta and variance pair is **partially supported**, not ABF-certified: regional precision exceptions, missing per-variant N/AF/QC, and material loss of the lead and other significant rows preclude a defensible whole-locus ABF package. The prior SuSiE/LD refusal neither proves nor disproves ABF validity. The stage has not run ABF.

Evidence: frozen `tracks/A/results/native_audit.json`, `EFFECT_CONTRACT_EVIDENCE.md`, `locus_summary_readiness.tsv`, `locus_variants_reference_checked.tsv.gz`, and this stage's complete row ledger. [Kim et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC8096488/) is the primary phenotype/method source. [coloc's input contract](https://chr1swallace.github.io/coloc/reference/check_dataset.html) requires a justified case-control fraction and preferably genuine beta/variance, not merely a signed direction.
