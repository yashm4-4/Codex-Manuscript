# GTEx v8 Lung FAM13A QTL input contract

**Decision: statistical fields available; regional package not execution-cleared.** The pinned 2023-04-06 eQTL Catalogue `QTS000015/QTD000271` **full** `.all.tsv.gz` is the uniformly reprocessed GTEx v8 bulk Lung gene-expression dataset in release 7 metadata: sample size 510, tissue `UBERON_0008952`, quantification `ge`, condition `naive`. Current pre-release 8 metadata reuses those IDs for GTEx v10 (601 samples); accession alone therefore does not identify the release. The source file date, release 7 metadata hash, index, and targeted extracted source are pinned in `acquisition_provenance.json`. FAM13A is `ENSG00000138640` in both source gene fields. The source does not contain a version suffix; its exact Ensembl gene version is **unreported**, and no `.15` version from GTEx v10 is imported into this analysis.

The full cis retrieval has 7,264 rows, including 254 extra rsID aliases, collapsing without conflicting statistics to **7,010 distinct GRCh38 REF/ALT variants**. The official permutation row independently reports `n_variants=7010`, confirming the test denominator. Observed tested positions span chr4:88,112,128–90,111,387 (GRCh38), consistent with the Catalogue's ±1 Mb window around the gene start; the precise gene-start coordinate is not supplied in the association file. The regional tabix request 4:87,000,001–94,000,000 encloses every official tested variant. All 7,010 REF alleles agree with an independently retrieved UCSC hg38 regional reference.

The [Catalogue field specification](https://github.com/eQTL-Catalogue/eQTL-Catalogue-resources/blob/master/tabix/Columns.md) defines ALT as the effect allele, `beta` as the linear regression coefficient, `se` as its supplied regression standard error, `pvalue` as the nominal association P, `maf` as tissue-specific minor allele frequency, `ac` as ALT count, and `an/2` as autosomal sample count. [Catalogue methods](https://www.ebi.ac.uk/eqtl/Methods/) describe normalized gene expression with inverse normal transformation and a ±1 Mb gene-start cis window. Quantitative `type="quant"`, beta and `se²` are therefore appropriate in principle. No P-derived variance is used. MAF is present (0.0107843–0.5). The dataset nominal N is 510, but per-variant AN ranges 970–1020: 99 of 7,010 variants have AN < 1020 (19 below 1000). A future scalar-N use needs a justified handling rule. `r2` is `NA` for every FAM13A row, so variant-level imputation quality is not verifiable from this slice; the source's tested-variant QC remains the documented pipeline criterion, not a measured field here.

The smallest nominal FAM13A P is 0.000559614; no variant has P < 5×10⁻⁸. The official gene permutation row has empirical `p_perm=0.598402` and adjusted `p_beta=0.604973`; the dataset's official credible-set file contains **zero FAM13A rows**. This is no evidence for a robust FAM13A lung eQTL signal in this pinned v8 release. It does not contradict the separately frozen GTEx **v10** exact significant pair: the releases and processing differ. Absence of a credible set is not proof of one or zero underlying biological signals.
