1. Freeze the test-stage specification before model inference
Before generating any chr8–9 model score, create and hash a prospective internal-test-1.0 specification.
Record that chr8–9 is:
- held out from V2 training;
- held out from V2 checkpoint selection;
- held out from chr7 calibration;
- not historically pristine, because V1 used these chromosomes and V2 construction/QC inspected outcome-blind covariates;
- therefore a fixed internal V2 holdout, not independent external validation.
No model-performance outcome from chr8–9 may alter this specification.
2. Fixed test population
Use only the already-frozen common C-task chr8–9 panels from pretraining-1.1.
Expected populations:
- enhancer: 12,695 positives + 12,695 controls;
- H3K27me3-associated: 1,754 positives + 1,754 controls.
Verify exact membership, role, component IDs, hashes, labels and sequence eligibility against the frozen manifests before inference.
Do not substitute rows or rebuild matching based on test outcomes.
3. Phase-I extraction
Extract frozen phase-I representations for these chr8–9 test sequences only.
Compute nucleotide forward and nucleotide reverse-complement representations independently through the original frozen phase-I model.
Never approximate RC by reversing representation columns.
Record:
- sequence count;
- encoded-identity count;
- geometry/QC;
- phase-I weight hash;
- forward/RC feature hashes;
- environment;
- compute use.
Any sequence, hash, geometry or phase-I mismatch is a hard stop.
4. Frozen checkpoints and ensembles only
Load the exact original published checkpoints from internal-training-1.0.
Verify their SHA-256 hashes before inference.
Evaluate:
- V2-A enhancer, all three frozen seeds;
- V2-B enhancer, all three frozen seeds;
- V2-C enhancer, all three frozen seeds;
- V2-A H3K27me3-associated, all three frozen seeds;
- V2-B H3K27me3-associated, all three frozen seeds;
- V2-C H3K27me3-associated, all three frozen seeds.
Use the already-frozen inference rule:
q_s(x) = [p_s(x) + p_s(RC(x))] / 2
and fixed equal-three-seed float64 ensemble:
Q(x) = mean_s q_s(x)
No seed weighting, checkpoint replacement or favorable-seed selection.
5. Test-set RC invariance
Verify actual-network symmetric-inference invariance on every frozen test-panel sequence:
Q(x) == Q(RC(x))
under the previously frozen numerical tolerances.
Check every seed and every ensemble for A/B/C in both contexts.
Failure is a hard stop.
6. Primary common-panel test evaluation
Evaluate A, B and C on the same frozen C-task chr8–9 panel within each context.
Report per-seed and ensemble:
- AP;
- AUROC;
- Brier score;
- Brier skill;
- fixed reliability bins.
Use the existing global overlap/encoded-sequence components as the bootstrap unit.
Perform the same fixed 2,000-valid-replicate component bootstrap framework used internally, with its prespecified invalid-draw safeguards.
Report 95% confidence intervals.
A/B/C comparisons are diagnostic ablations only.
Report paired:
- B − A;
- C − B;
- C − A
for AP, AUROC and Brier.
Do not require C to outperform B.
Test performance must not change the already-frozen model configuration.
7. Prospective C holdout-generalization gate
Before viewing test outcomes, record the following fixed test-stage release rule separately for enhancer and H3K27me3-associated C:
Require:
- all three frozen C seeds evaluable;
- real-network RC invariance PASS;
- all predictions finite and within [0,1];
- required test sample/component counts present;
- 2,000 valid component-bootstrap replicates under the frozen procedure;
- invalid-bootstrap fraction <0.10;
- lower 95% CI AUROC >0.5;
- lower 95% CI AP-minus-replicate-prevalence >0;
- lower 95% CI Brier skill >0.
Also report seed AP SD and range using the same definitions as chr7. Apply the existing stability limits prospectively:
- sample SD ≤0.03;
- range ≤0.10.
These are internal generalization safeguards, not clinically meaningful effect-size thresholds.
If either C context fails or is inconclusive:
STOP.
Do not open the external benchmark.
Do not redesign or retrain within this version.
Report the failed condition for investigator review.
