**Public Pan-UKB EUR LD source contract — Tracks C and A**

The acquired Pan-UKB EUR resource is a legitimate signed dosage-based, covariate-adjusted matrix reference. It is suitable for the authorized input diagnostics. Its public origin and numerical usability do not alone establish the source/statistic/sample contract required for statistical fine-mapping. Track C has a same-project near-overlap relationship; Track A would use an external full-European UKB reference. Neither is certified here as exactly matched phenotype-specific in-sample LD.

The exact public resources are `s3://pan-ukb-us-east-1/ld_release/UKBB.EUR.ldadj.bm` and its `UKBB.EUR.ldadj.variant.ht` index. Downloaded metadata specify a **23,960,350 × 23,960,350** matrix with block size **4,096**; the index partition counts independently sum to **23,960,350**. Actual index globals give **420,542 EUR samples**. Native keys are GRCh37 locus plus ordered REF/ALT alleles, with ALT dosage as the counted contrast. Root retrieves only the blocks required by GWAS-defined loci. Checksums, object versions and original part bytes remain recorded; no participant genotypes are acquired.

Provider documentation describes dosage standardization, linear covariate adjustment, a signed product scaled by sample count, a 10-Mb band and triangular storage. Its covariates are an intercept, age, sex, age squared, the two age-by-sex terms and ten ancestry PCs. Historical code points to UKB version-3 imputed BGEN dosages, with missing dosages mean-imputed before transformation. Official UKB background identifies the HRC and UK10K/1000 Genomes panels underlying this era of imputation. The documented LD input filtering is INFO>0.8 and population MAC around 20. These facts identify the resource; the exact executed filter parameters require the provenance qualification below. [Pan-UKB LD methods](https://pan.ukbb.broadinstitute.org/docs/ld/), [historical genotype helper](https://github.com/atgu/ukbb_pan_ancestry/blob/fb0bfcf2dcf1f6d699bc6845cd561f43987e53c2/resources/genotypes.py), [official UKB genotype background](https://community.ukbiobank.ac.uk/hc/en-gb/articles/15468170680605-Genome-wide-genotyping).

Historical source provenance was examined rather than assuming that current `master` produced the release. The matrix metadata object was last modified **2020-10-24 03:24:29 UTC**. GitHub history places the latest repository snapshot before that timestamp at **`fb0bfcf2dcf1f6d699bc6845cd561f43987e53c2`**, dated October 22. Its `compute_ld_matrix.py` is identical to the last pre-object file commit **`581432c1761616092fa45fc504b55dabaab59185`**, dated June 25; the file SHA-256 is **`73382283b7fc55022b2dcf0c8e9b30ff3770df1c201708fe7d13af5ccb8776e3`**. Both this version and the October 25 update use the same core transformation: standardize dosage first, residualize against covariates, then form `G=Z Zᵀ/n`, apply the 10-Mb band and retain a triangle. Neither performs a second per-variant variance normalization after covariate residualization. [Pinned pre-object implementation](https://github.com/atgu/ukbb_pan_ancestry/blob/fb0bfcf2dcf1f6d699bc6845cd561f43987e53c2/compute_ld_matrix.py).

The immediately following public commit **`9abc15b60dd1a21f9cc60eb6725e76f819ad41f8`**, October 25, adds chromosome X and `min_mac=19`; the pre-object script uses autosomes and the helper's default 20. The actual released variant index includes X. Public commit chronology therefore does **not** identify the exact executed code or arguments, and code may have been run before it was committed. The October 22 genotype helper also explicitly compensates for a source frequency-table AF/AN scaling artifact. This is not evidence that the downloaded matrix is wrong; it is a reason to retain exact original execution lineage as unresolved. Archived versions, API receipts and their diff are under `tracks/C/sources/`. The provider subsequently announced LD in the October 29, 2020 v0.2 release. [October 25 update](https://github.com/atgu/ukbb_pan_ancestry/blob/9abc15b60dd1a21f9cc60eb6725e76f819ad41f8/compute_ld_matrix.py), [release chronology](https://pan.ukbb.broadinstitute.org/docs/changelog/).

The source code resolves why a raw diagonal can differ from one: residualization follows initial genotype normalization, so the stored object is a residualized standardized-dosage Gram product. A separately saved diagnostic correlation, `R_ij=G_ij/sqrt(G_ii G_jj)`, is a transparent mathematical derivation. Root preserves the original triangle and hashes the derived matrix; it does not reset the source diagonal, project to a PSD matrix, clip eigenvalues or fill missing within-band correlations. This derivation does not establish that `R` is the covariance required by either source GWAS statistic.

For Track C, the checksum-bound flat file is a 2023 object. Current public Hail metadata, from a container modified in 2024, identify exact J44 EUR analysis counts and **SAIGE 0.36.3**, with `inv_normalized=false`. The version-pinned SAIGE code constructs binary SE from beta and the saddlepoint P value: `SE=abs(logOR/qnorm(SPA_P/2))`. Thus complete-file beta/SE/P agreement is an arithmetic/export check, not independent evidence for an unadjusted Gaussian/Wald likelihood. The original signed beta contrast remains interpretable. The scientific inference from comparing the implementations is that an unweighted residual genotype correlation and a calibrated mixed-model score statistic need an explicit covariance/likelihood justification before RSS execution. No alternative z was manufactured from P. [Pan-UKB GWAS methods](https://pan.ukbb.broadinstitute.org/docs/qc/), [pinned SAIGE 0.36.3 code](https://github.com/weizhouUMICH/SAIGE/blob/f5c757dfe5e2c872d2034845c2d9b5c867af773e/R/SAIGE_SPATest.R), [SAIGE methodological paper](https://www.nature.com/articles/s41588-018-0184-y).

Phenotype-level N is known for C, but variant-level GWAS N is absent. The separate variant QC manifest has EUR AN/2 of 458,317–458,937, a broader cohort, and cannot replace the J44 sample size. LD N=420,542 likewise cannot be silently substituted for GWAS N=420,531. The sample difference is not, by itself, a demonstrated fatal mismatch; nor does its small size establish equivalence. A documented near-overlap reference assumption plus an appropriate statistical contract would need explicit scientific review.

For Track A, shared UKB origin and European ancestry make the public matrix a plausible reference to investigate. They do not recreate the ever-smoker subset, its case/control ascertainment, sample QC or covariate processing. Smoking selection can change joint genotype/covariate distributions; the available absent-AF/N/INFO Kim schema cannot establish that any difference is negligible. No exact public smoking-subset matrix was identified in the governing evidence or this route. An author-provided compatible LD release or an appropriately approved genotype-derived route would be separate access-dependent possibilities. No access request was sent and no participant data were accessed. [Track A audit](../tracks/A/TRACK_A_REPORT.md), [UKB controlled-access description](https://www.ukbiobank.ac.uk/about-our-data/).

A and C also share UKB source participants and cannot be claimed as independent replication tracks or combined as independent evidence. Their exact overlap is not documented here. BBJ's independent ancestry/source question is audited separately under Track B; no convenient substitute ancestry panel is introduced by this contract.

The authorized diagnostics can establish exact allele/index mapping, retained order, finite signed values, valid triangle reconstruction, explicit scaling, symmetry/range, PSD behavior, numerical rank and conditioning, null-space projections, retained/missing strong signals and locus/band boundaries. Conditional residuals and a scalar null-covariance mismatch diagnostic can expose incompatibilities under the stated diagnostic model. They cannot recover historical sample identities or execute-code provenance, validate a missing per-variant N derivation, prove the binary-score covariance approximation, establish Kim subgroup equivalence, or rule out LD beyond the stored 10-Mb band. Multiple signals can also produce conditional residuals. No universal residual/mismatch threshold is invented after seeing results.

Provider `high_quality` is retained as a distinct annotation: it combines gnomAD-genomes PASS with multi-population frequency concordance. It is not identical to EUR phenotype-specific `low_confidence`, MAC or INFO. False flags are not a blanket exclusion and do not redefine loci; strong flagged variants remain visible in the source and overlap ledgers. Source-QC/identity failures remain explicit under the frozen rules.

Source identity and matrix numerics therefore support a diagnostic reference, while **source/statistic/sample clearance remains unresolved** until the listed evidence gaps and all locus-specific gates are closed. The final stage readiness tables integrate the actual diagnostics. Neither this contract nor a numerical pass authorizes SuSiE-RSS/FINEMAP. `source_contracts.json` contains the machine-readable audit and source links.
