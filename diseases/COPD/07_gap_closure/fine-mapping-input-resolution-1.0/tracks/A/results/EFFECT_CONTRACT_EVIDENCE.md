# Track A source-statistic evidence

GCST90016588 is the UK Biobank ever-smoker marginal spirometric COPD case-control analysis, with 12,446 cases and 59,145 controls. Its native Catalog submission explicitly labels `effect_allele`, `other_allele`, `odds_ratio`, and `standard_error`. The separately acquired Catalog harmonized file is GRCh38; the native submission is GRCh37. Native locus coordinates are never replaced by harmonized coordinates.

The [Kim primary paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC8096488/) describes marginal GWAS within smoking strata, alongside distinct interaction models, using PLINK 2.0. The stated marker inclusion thresholds are MAF at least 0.01 and imputation quality r² at least 0.5. This track uses the marginal ever-smoker accession, not a joint or interaction coefficient. The historical exact PLINK command and submission-conversion script are not supplied in the retrieved release. The article is archived in `sources/kim2021_pmc.html`.

[PLINK's official format definition](https://www.cog-genomics.org/plink/2.0/formats#glm_logistic) associates OR with the tested allele, specifies SE on the log-odds coefficient scale, and distinguishes Wald Z statistics from joint-test statistics. This establishes the documented software convention; it does not establish the exact historical command. The submission schema, full-file numerical tests and independently preserved raw-to-harmonized transformations supply the accession-specific checks. The prospective transformation is natural-log(OR), with the supplied SE, not an SE inferred from P. Documentation is archived in `sources/plink2_formats.html`.

[Catalog harmonization documentation](https://www.ebi.ac.uk/gwas/docs/methods/summary-statistics/) records allele swaps, strand complements and reciprocal-OR changes. Codes 5/6 assume palindromic strand; they do not independently resolve the missing frequency evidence required by the preflight's stricter analysis-identity contract. The full-file transport audit uses an exact tuple of original association fields, excluding coordinates solely because those coordinates are lifted. That provenance crosswalk is never used as an analysis identity join.

Rounding-aware tolerances were saved in `config/effect_contract.json` before full-file acquisition or numerical inspection. The audit propagates intervals implied by the printed decimal precision of OR, SE and P. It tests the entire file and exports an additional deterministic chromosome/P-band sample. A failed row remains failed; alleles or SE values are never changed to improve numerical agreement. Rounded OR values whose intervals contain 1 remain direction-unresolved. Risk direction remains a source-GWAS algebraic interpretation, separate from statistical significance, causality and downstream regulatory evidence.
