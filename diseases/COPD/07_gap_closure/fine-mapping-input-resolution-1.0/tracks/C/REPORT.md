**Track C — Pan-UKB ICD10 J44, both sexes, EUR: completed GWAS input audit**

The complete public J44 file was acquired and validated. It supports a verified signed native GWAS contrast and seven prospective GWAS-only merged intervals, of which one is deferred as MHC. This audit does not grant statistical fine-mapping clearance. The root stage separately evaluates LD, the sampling-model contract, and execution readiness. The phenotype remains a secondary EHR/ICD COPD sensitivity.

The exact complete file is `data/icd10-J44-both_sexes.tsv.bgz`: 1,827,545,082 bytes; provider MD5 `787f3a8ce3502a9a8f597a17144e07ae` matches; SHA-256 `cd0b714c62813812c2284923ac0b0b9ee76e5c47ba1f4a3d2ad2f68574ef8a15`. Complete gzip decoding/CRC and all **28,987,534** rows were checked, covering chromosomes 1–22 and X. Its current provider object is dated 2023-02-09 and uses the v0.4 negative-log10-P schema. Acquisition receipts preserve URL, timestamps, headers and object version.

Only `beta_EUR`, `se_EUR`, `neglog10_pval_EUR`, EUR AF fields and EUR confidence flags supplied association statistics. Other source fields were counted for missingness, without analyzing their associations. There are **23,861,813 valid signed EUR records**, including **18,782,362** with `low_confidence_EUR=false`, **18,170,886** of them autosomal. EUR statistics are missing in 5,125,720 union-file rows; 5,079,452 are flagged low-confidence. Exact native allele-key duplicates are zero, independently checked including complete groups across parser chunk boundaries. There are 51,154 additional allelic rows at repeated positions, 1,998,058 indel/multibase rows and 4,213,257 palindromic SNP rows. Native allele syntax, coordinates and source ordering pass.

One nonmissing source row is invalid: row 22,249,947, `14:37793829:G:T`, has SE=0, negative-log10-P=`Infinity`, both AFs=1 and source low-confidence=true. It was excluded before locus definition and retained unchanged in `results/whole_file_invalid_numeric_rows.tsv`. No source value was repaired.

The provider defines GRCh37 coordinates, forward-strand REF/ALT and **ALT as the effect allele**. Binary beta is signed log-OR; z is computed solely as supplied beta/SE. P is `10^(-neglog10_pval_EUR)`, retaining the log value. The phenotype release manifest specifies **11,536 cases and 408,995 controls (N=420,531)**. Per-variant GWAS N is absent; it is not replaced by an effective N or a broader cohort allele number.

All valid EUR rows agree between reported P and beta/SE within prospectively frozen intervals implied by printed precision. The deterministic retained sample spans every chromosome and significance band, all significant records and every 1,000th source row. **This agreement verifies arithmetic, not an independent Wald likelihood.** Exact J44 EUR metadata in the current public Hail column container reports SAIGE 0.36.3 and no inverse normalization. Archived SAIGE source commit `f5c757dfe5e2c872d2034845c2d9b5c867af773e` verifies version 0.36.3 and the binary formula `SE = abs(logOR/qnorm(SPA_P/2))`. Consequently, beta/SE is a signed SPA-equivalent statistic. Its covariance relationship to genotype LD still requires the separate sampling-model/compatibility gate. No replacement z was inferred from P. The Hail column container is dated 2024 whereas the checksum-bound flat file is dated 2023; EUR case/control counts agree, but exact original execution provenance is not established merely by the current metadata. Across-ancestry full-cohort metadata differ and are not substituted.

Loci use only valid, source-confidence-pass EUR autosomal variants with P<5e-8, ±1,500,000-bp closed windows, chromosome clipping, transitive overlap merging, and deterministic significance/coordinate/allele/source-row ties. There are **334 seed variants**. The conservative MHC rule defers the entire intersecting merged interval. Boundaries were not revised according to biological annotations, QC outcomes or LD availability.

The complete provider variant QC manifest was also acquired and decoded: **28,987,534 rows**, 2,701,503,051 bytes, MD5 `e70ebc8289f762dd8d5086f54e766654` matching its single-part provider ETag. Every locus source key has a counterpart. Only identity, rsID, INFO, QC and EUR frequency/allele-number columns were parsed; gene annotations were not parsed or used. The manifest's EUR AN/2 ranges **458,317–458,937**, so it is broader than both J44 N and the LD cohort. It cannot supply variant-specific J44 N. Printed INFO ranges 0.8–1.0; 397 full-manifest rows print 0.8 despite the documented upstream >0.8 filter. Two occur in these loci and remain explicitly flagged as precision-boundary ambiguity, not repaired or used to redraw loci.

Provider `high_quality` combines gnomAD-genomes PASS with AF concordance across four available ancestry groups. It is distinct from EUR phenotype-specific `low_confidence` and the upstream INFO filter. It was **not an automatic exclusion** from seed selection, signed direction or the diagnostic-join set. False flags remain visible, including 2 significant rows in C_L001, the deferred MHC seed, 16 significant rows in C_L006 and the sole C_L007 lead. Root LD/compatibility evaluation must retain and assess these strong-signal flags.

`results/locus_variants.tsv.gz` contains the explicit `native_signed_ld_join_eligible` Boolean: source statistic QC PASS and a VERIFIED harmonization status. It does not impose a `high_quality` filter. This denotes eligibility for diagnostics only. `results/ld_join_contract.json` records the exact rule. `results/excluded_or_flagged_variants.tsv.gz` includes both exclusions and annotations; presence there is not itself an exclusion rule.

`results/risk_direction.tsv.gz` contains all locus rows: **175,749** have a signed observed disease-increasing allele, and **83,503** are explicitly unresolved. Direction follows the verified beta sign in the native ALT/REF contrast, with no candidate/model/functional evidence and no causal claim. Source-confidence/identity failures and the INFO precision boundary are withheld conservatively. The non-MHC intervals contain 125,967 assigned directions. Signed direction does not imply fine-mapping eligibility.
