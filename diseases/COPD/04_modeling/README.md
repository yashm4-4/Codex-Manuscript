# Section 4: Modeling

Status: complete for the public computational scope on 2026-10-01.

The section trained and held out enhancer and silencer TREDNet models for one
ENCODE severe-emphysema bulk-lung donor, scored paired alleles for the frozen
15,389-record candidate set, nominated 337 predicted causal regulatory
candidates, ran DeepFootprinting and allele-specific motif analysis, annotated
1000 Genomes frequencies and ancestral states, mapped provisional target
genes, audited recovery of experimentally studied variants, and generated THE
LIST.

The integrated report is `results/section_4_modeling.md`. The primary ranked
output is `results/COPD-S4-R010_THE_LIST.tsv`. All claims retain the
one-donor, bulk-tissue, LD-expansion, provisional-target, and
computational-prediction limitations.
